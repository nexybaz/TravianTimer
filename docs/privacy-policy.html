3. Apple Sign-In

Bei Nutzung von "Mit Apple anmelden" erhalten wir ausschliesslich den von Apple bereitgestellten Identity-Token sowie optional den Namen und die E-Mail-Adresse. Wir haben keinen Zugriff auf das Apple-ID-Passwort.

4. Biometrische Daten

Die optionale App-Sperre nutzt Face ID oder Touch ID ueber das Apple-Betriebssystem. Es werden keine biometrischen Daten gespeichert oder uebertragen. Die Auswertung findet ausschliesslich auf dem Geraet statt.

5. Datenspeicherung

Alle Daten werden auf Servern von Supabase (EU-Region) gespeichert. Die Uebertragung erfolgt verschluesselt via HTTPS/TLS. Authentifizierungs-Tokens werden im iOS-Schluesselbund (Keychain) auf dem Geraet gespeichert.

6. Tracking und Analyse

Die App verwendet kein Tracking. Es werden keine Analyse-Dienste, Werbe-Netzwerke oder Drittanbieter-SDKs fuer Nutzerverfolgung eingesetzt. Es erfolgt keine Weitergabe von Daten an Werbetreibende.

8. Discord-Integration

Die App kommuniziert nicht direkt mit Discord. Die Verbindung erfolgt ausschliesslich serverseitig ueber eine Supabase Edge Function. Dabei werden Spielername, Dorf und Truppeninformationen im Zusammenhang mit Deff-Calls uebermittelt.

9. Datenweitergabe

Personenbezogene Daten werden nicht an Dritte verkauft oder zu Werbezwecken weitergegeben. Eine Weitergabe erfolgt ausschliesslich an die unter Punkt 7 genannten Dienste im Rahmen der App-Funktionalitaet.

10. Account loeschen

Der Account kann jederzeit in den App-Einstellungen unter "Account" geloescht werden. Bei Loeschung werden alle gespeicherten Daten (Profil, Doerfer, Truppen, Pledges, Benachrichtigungen) unwiderruflich entfernt.
